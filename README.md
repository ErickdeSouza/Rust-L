## Observações e Lembretes!


#### Tipos primitivos:

- Inteiros com sinal ->  i8 i16 i32 i64 i128 isize
- Inteiros sem sinal ->  u8 u16 u32 u64 u128 usize	(só valores ≥ 0)
- Ponto flutuante    ->  f32 f64
- Booleano           ->  bool true ou false
- Caractere          ->  char (um valor Unicode [4 bytes]
